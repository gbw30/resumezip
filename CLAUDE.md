# Commits and pull requests

- A commit is authored by the person running the session, never by `Claude <noreply@anthropic.com>`. Before committing, check `git var GIT_AUTHOR_IDENT`. If it shows that address, stop and ask whose name to commit under.
- No `Co-Authored-By`, `Claude-Session` or other attribution lines in commit messages.
- Nothing about Claude in commit messages, pull request titles or descriptions. If a "Generated by Claude Code" line is added to a pull request description, edit it out.
- Name branches after the change (like `quieter-write`), not `claude/…`: the branch name goes into the merge commit.
- Don't post comments or reviews on GitHub. Write the text and hand it over, for a person to post.
